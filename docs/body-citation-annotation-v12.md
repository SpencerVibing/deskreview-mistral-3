# Body Citation Annotation v12

Status: rejected bounded experiment; production remains on
`deskreview_body_citations_v10`.

The v12 experiment preserves the v11 exact-copy design and makes the raw OCR
packet boundary explicit:

- citations visible elsewhere on the PDF page are outside scope;
- parenthetical and bracketed groups must retain both delimiters;
- narrative citations, including single-author forms, must retain the author
  text before the year parentheses;
- raw OCR code points take precedence over visually corrected PDF typography.

Passive validation remains unchanged. Relation v4 remains frozen.
